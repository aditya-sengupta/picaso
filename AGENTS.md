Always work in the conda env "picaso4".
Never run multi-line scripts directly with python -c; always write a script instead.
Do not run any Git commands that modify the picaso/ directory, e.g. checkouts, commits, merges.
The convention for converting between g and logg is: g numbers are in m/s^2, and we want log g in cm/s^2. So g = 31 corresponds to log g = 3.5, g = 100 corresponds to log g = 4.0, and so on.
